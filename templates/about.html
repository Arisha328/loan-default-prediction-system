How LoanAI works

The Dataset

The model is trained on a historical loan-performance dataset with over 250,000 records. Each row describes an applicant — age, income, credit score, employment history, existing debt — along with whether that loan ultimately defaulted.

  • 17 input features per applicant
  • Numeric fields: age, income, loan amount, credit score, months employed, credit lines, interest rate, loan term, DTI ratio
  • Categorical fields: education, employment type, marital status, mortgage, dependents, loan purpose, co-signer
The Model

A class-balanced Logistic Regression classifier, chosen for its speed and interpretability — every coefficient maps directly to a feature, which is what powers the "Why this verdict?" explanations on each result page.
